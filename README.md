🐸 Tung Tangle

Tung Tangle is a browser-based adventure and battle game where you train your Tung, explore the world, collect items, fight rivals and eventually become the ultimate Alpha Tung.

🎮 Features

- 🐸 Train your Tung
- ⚔️ Battle rival Tungs
- ⭐ Gain XP and level up
- ✨ Evolve your Tung
- 🌲 Explore different areas
- 🎒 Collect and use items
- 🗺️ Travel around the Tung world
- 💾 Save your progress
- 📂 Load your progress
- 🏆 Become the Alpha Tung

🧬 Evolution

Your Tung can evolve as it becomes stronger:

Level 1

- Tung

Level 5

- Mega Tung

Level 10

- Alpha Tung

🌐 Running the Game

No Python or Pygame is required.

Simply open:

index.html

in a modern web browser.

🚀 GitHub Pages

You can host the game using GitHub Pages.

1. Create a GitHub repository.
2. Upload:
   - "index.html"
   - "style.css"
   - "game.js"
   - "README.md"
3. Open the repository's Settings.
4. Find Pages.
5. Set the deployment source to your main branch.
6. Save the settings.
7. GitHub will give you a website address.

The game will then run directly in the browser.

💾 Saving

Tung Tangle uses your browser's "localStorage" system to save the game.

Your save is stored locally in the browser you are playing on.
